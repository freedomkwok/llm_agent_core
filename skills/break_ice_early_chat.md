# Skill: 刚认识阶段对话分析与破冰

## 目标
当用户提供刚认识阶段的聊天截图、聊天记录、拟发送消息，或询问“这样回可以吗 / 对方什么意思 / 怎么破冰 / 要不要推进微信或见面”时，帮助用户：
- 判断当前互动节奏
- 识别用户上一句属于哪种社交动作
- 判断推进是否过快、过直、过任务化
- 找到当前真正卡点
- 给出低风险、自然、不尴尬的下一步回复

## 适用条件
- 刚认识
- 对方有回复意愿
- 用户在意节奏、分寸、体面

## 禁止行为
- 不要鼓励死缠烂打
- 不要把正常边界解释成欲擒故纵
- 不要建议过度自信或施压式推进
- 不要只给一句回复，不做分析

## 输出格式
1. 当前节奏判断
2. 对方这句话的潜台词
3. 你上一句的问题
4. 当前真正卡点
5. 建议回复（自然版 / 幽默版 / 轻推进版）
