Layer 1: Skill registry

	•	管理所有 skill.md
	•	提供 discovery metadata
	•	支持 selection

Layer 2: Skill interpreter

负责把 skill 文件变成 runtime 可执行对象，比如：
	•	steps
	•	preferred tools
	•	stop conditions
	•	output policy

Layer 3: Generic execution engine

负责：
	•	调 tool
	•	维护 state
	•	按 steps 往下走
	•	把结果反馈回 skill interpreter

  from pathlib import Path
import yaml

class SkillSpec:
    def __init__(self, name, description, when_to_use, when_not_to_use,
                 required_tools, execution_text):
        self.name = name
        self.description = description
        self.when_to_use = when_to_use
        self.when_not_to_use = when_not_to_use
        self.required_tools = required_tools
        self.execution_text = execution_text

def load_skill(path: str) -> SkillSpec:
    raw = Path(path).read_text(encoding="utf-8")
    if raw.startswith("---"):
        _, frontmatter, body = raw.split("---", 2)
        meta = yaml.safe_load(frontmatter)
    else:
        raise ValueError("skill file missing frontmatter")

    return SkillSpec(
        name=meta["name"],
        description=meta["description"],
        when_to_use=meta.get("when_to_use", []),
        when_not_to_use=meta.get("when_not_to_use", []),
        required_tools=meta.get("required_tools", []),
        execution_text=body.strip(),
    )
